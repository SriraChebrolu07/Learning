# Learning

Python, SQL, and introductory AI learning exercises collected while building
foundations in programming, databases, web retrieval, and application work.

## Contents

- `learning/python-basics` — Python syntax, functions, OOP, files, and algorithms
- `learning/python-sql` — Python and SQL practice
- `learning/daily-tasks` — Small application and database exercises
- `learning/web-rag` — Early web ingestion and retrieval experiments

These examples are educational and may require older library versions or local
services. Keep credentials in a local `.env` file and never commit that file.
